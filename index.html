Everything runs locally with zero dependencies. The dino is a position-based-dynamics skeleton: 13 particles, 22 distance constraints, 11 angle constraints, motor-driven joint targets, and a dead state where every muscle goes limp and the body tumbles. Because the module publishes game.controller, an LLM or a script can drive it too: 

game.controller.press('jump')
game.controller.setAuto(true)
await game.controller.step(120)      // headless, fixed-step
game.getState()                       // { score, state, dino: { pose, ... } }
